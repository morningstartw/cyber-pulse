# 🎮 CYBER PULSE: OVERDRIVE V2.0 (賽博超頻：大擴充)

一款專為手機與電腦瀏覽器打造的高效能**賽博霓虹肉鴿生存遊戲（Cyberpunk Roguelite Survivor）**。

---

## ✨ V2.0 新增特色

1. **⚡ 主動閃避衝刺系統（Dash System）**：
   - 帶有短暫無敵幀（i-frames）與帥氣霓虹殘影。
   - 衝刺穿透怪物時免受傷害，並在地面留下高能電弧灼燒擊退路徑。
   - **操作**：電腦端按 `空白鍵 (Space)` 或 `Shift`；手機端點擊右下角霓虹專屬 `DASH` 按鈕（具備冷卻轉圈動畫）。

2. **🚀 戰術機庫（3 款特色可選戰機）**：
   - **【PULSE-01 突擊者】（預設解鎖）**：均衡機體，開局持脈衝光砲，自帶 +10% 暴擊率加成。
   - **【PHANTOM-X 幽靈】（150 核心解鎖）**：高機動刺客，航速提升 25%、具備 **2 次連續衝刺充能**，開局持旋轉光刃，身形極度飄逸。
   - **【TITAN-IX 泰坦】（250 核心解鎖）**：重裝高生命裝甲，開局自帶連鎖電弧與相位能量護盾，撞擊敵人造成巨額反傷。

3. **🌌 金色傳奇武器融合（Super Fusion Weapons）**：
   - 當兩把特定武器升至滿級（LV.5）時，升級提供金色超武：
   - ⚡ **光砲 + 電弧 ➔【天基天譴軌道砲】**：自天際降下毀滅級貫穿離子光柱，並引發全螢幕連鎖天罰雷暴！
   - 🌀 **光刃 + 脈衝波 ➔【虛空引力黑洞】**：召喚高速旋轉的時空黑洞，吸扯全場所有敵機進入核心粉碎！
   - 🪐 **浮游機 + 護盾 ➔【神盾守護母艦】**：全域防衛矩陣，生成巨額護盾並傾瀉無盡微型追蹤導彈！

4. **⚙️ 局外晶片天賦樹（Meta-Progression）**：
   - 永久強化生命、武器傷害、移動速度、量子磁力吸晶範圍、冷卻縮減與暴擊率。

5. **🔊 Web Audio 原生合成電子音效**：
   - 內建 Synthwave 復古電子節奏 BGM、衝刺音效、黑洞重力音效與天譴光束打擊音效，零外載音檔，秒開不卡頓。

## 🚀 如何快速遊玩

### 方式 1：直接雙擊開啟
- 在檔案總管中雙擊 [`index.html`](file:///c:/ai%20agent/game%20for%20friends/index.html) 即可在瀏覽器中秒開遊玩！

### 方式 2：本機伺服器（推薦）
在終端機中執行：
```bash
npm start
```
開啟瀏覽器前往：`http://localhost:3000`

---

## 📱 分享給朋友的方式（零安裝秒玩）

- **部署到 Vercel**：執行 `npx vercel`，登入後即可取得免費公開網址（如 `https://your-game.vercel.app`）。
- **手機加為主畫面**：朋友們在 iPhone 或 Android 點開連結後，可以在瀏覽器選單點擊「**加入主畫面**」，就會像原生 App 一樣以獨立全螢幕運行！
